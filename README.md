# Manglam Jewellers Website

White-and-gold responsive website for Manglam Jewellers, Ghaziabad.

## Features
- Gold rates: 24K, 22K, 20K, 18K and silver
- Manual rate editing with per-gram and per-10-gram display
- Product gallery with category filters
- Shared admin password, multiple admins
- Product photo upload and deletion
- WhatsApp enquiries, Instagram and Google Reviews link
- English/Hindi text toggle
- Google Apps Script backend

See `SETUP-GUIDE.txt` before publishing. Add the original logo as `assets/manglam-logo.png`.
